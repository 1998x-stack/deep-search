# Factory v0.3 — independent engineering review, 2026-11-13

Review target: `factory/cleanrl-deepseek-google-v1` (parent branch).
The main branch is not in scope for modification. Review source was fetched
from GitHub, including tests, workflow, LLM/search providers, evidence checks,
Reflection state machine, fetcher, CLI and capability contracts.

## Findings and remediation

| Severity | Finding | Proof from source | Disposition |
| --- | --- | --- | --- |
| HIGH | Non-strict run could return `completed` with no full-text anchored claim. `evidence.audit` only checked structural errors; zero claims/no citations generated no errors. | `factory/pipeline.py`, `factory/evidence.py` | FIXED: independent `assess_research_readiness` gate in all modes; regression for snippets-only and empty ledger |
| MEDIUM-HIGH | Direct `ResearchConfig(llm="openai")` inherited DeepSeek model and host defaults. CLI selected OpenAI correctly, but library use did not. | `factory/config.py` | FIXED: provider-aware dataclass defaults and regression tests |

| MEDIUM | Structural audit could accept a falsified `anchored=true` item with an empty quote because an empty string is a substring of any content. | `factory/evidence.py` | FIXED: refuse empty quotation anchors; unit test |
| MEDIUM | Source-index citations could count as in-body support when the heading delimiter differed; test also initially used literal backslash-n. | `factory/evidence.py`, `tests/test_evidence.py` | FIXED: heading-level split and corrected newline regression |
| MEDIUM | HTML fetch public-DNS preflight is not IP-pinned across HTTPS connection. DNS rebinding/TOCTOU remains possible. | `factory/fetch.py` | OPEN: only run on trusted, egress-restricted host; before public/multi-tenant deployment, pin resolved IP and enforce network egress |
| MEDIUM | No real-provider end-to-end evaluation or labeled factuality benchmark, despite offline CI. | `tests/`, `evals/` | OPEN: perform authorized paid API live smoke, browser access verification, labeled source/contradiction evaluation |

## Evidence confidence boundary

`audit.json.valid=true` and `audit.json.readiness.ready=true` establish a
bounded *technical/provenance completeness threshold*, not statistical
confidence, independent corroboration or factual entailment. Claims still
require independent methodological review.

## Tests and CI

The PR includes targeted tests in `tests/test_config.py`,
`tests/test_evidence.py` and `tests/test_pipeline.py`. CI runs Python
3.10/3.12 unit suites, a synthetic offline benchmark and an optional
real-Chromium test using intercepted synthetic DOM, not real search.

CI results must be linked to the actual run after all jobs complete.
No live credentials have been provided to this review session.
