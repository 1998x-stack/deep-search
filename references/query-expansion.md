# Query expansion playbook

Build distinct query families rather than slight rephrasings of the same assertion.

- **Entity/terminology:** full names, aliases, native script, abbreviations, former names and legal entity names.
- **Primary evidence:** site-restricted official records, original studies, annual reports, court judgments, regulations, repositories.
- **Chronology:** dates before/after a reported incident; revisions; policy implementation milestones.
- **Quantification:** totals, denominators, data definitions, geographic limitations, time windows, methodological appendices.
- **Adversarial:** denial, correction, retraction, expert disagreement, failed replication and alternative causal mechanisms.
- **Cross-language:** original-language terms plus concise English equivalents; avoid pretending direct machine translation is verified.

For each query: record goal, language, provider, terms, result IDs and the gap addressed. Avoid query strings that already assume the answer; a query like `evidence fraud by X` must be paired with neutral and counterfactual searches. Never infer a source exists solely because a query mentions it.
